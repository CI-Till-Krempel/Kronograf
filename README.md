# Kronograf

Kronograf is a time-tracking tool for freelancers and teams. This initial version provides a command-line interface for core time-tracking functionality.

## How to Run

1.  **Prerequisites**: Python 3.7+
2.  **Run the application**:
    ```bash
    python -m src.kronograf.main
    ```

## Commands

-   `start`: Starts a new timer.
-   `stop`: Stops the currently running timer.
-   `describe <text>`: Adds a description to the current time entry.
-   `exit`: Exits the application.
